What it does

Your model, your machine

Any OpenAI-compatible URL, or Claude over Anthropic's own API. On first run byob finds the servers already running on this computer and offers presets for hosted APIs. Save several models and give each a job: subagents, image descriptions, chat titles.

Work beside the chat

Spreadsheets (xlsx and csv), charts, Markdown documents, images and HTML apps open next to the conversation, each with its own version history.

Projects

A project is a name, instructions every chat in it follows, and the folders its chats work in, as many as it needs. Find any of them from the search palette (Ctrl+K).

Reads your stuff

PDF, Word and PowerPoint files, images for models that can see, the web, your mail over IMAP and your calendar over CalDAV. Notes it keeps across chats are plain Markdown.

On your phone too

The browser UI is the same app compiled to WebAssembly, live on the same session. Put it behind tailscale serve and it follows you around.

Knows how fast it is

/bench measures your model: tokens per second, prompt speed and time to the first token, at every number of parallel requests your server allows.

It finds the server you already have

  • Ollama

  • OpenAI-compatible APIs

On first run byob looks on their usual ports and offers presets for hosted APIs.

A few things to know

Is it as good as Claude or ChatGPT?

It's as capable as the model you point it at. Connect it to Claude and you get Claude, with byob's files, apps, spreadsheets and plugins around it. A small local model is faster and private, but it will make more mistakes on long tasks.

Do I need a GPU or a server?

Not if you use a hosted model: an API key, or the Claude or ChatGPT plan you already pay for (through Claude Code or Codex, if you have them installed). To run models on your own computer you need llama.cpp, Ollama, LM Studio or vLLM, and hardware that can run the model you choose.

What leaves my computer?

Your messages and the files you share go to the model server you set up, and only there. byob has no account, no telemetry and no server of its own. The web, mail and calendar tools reach those services only when you use them.

macOS says byob can't be opened.

byob isn't signed by an Apple developer yet. Try to open it once, then choose Open Anyway in System Settings → Privacy & Security. Or fetch it from a terminal, which skips the check:

v=0.3.10 t=aarch64-apple-darwin   # x86_64-apple-darwin on Intel
curl -L https://github.com/Scronkfinkle/byob/releases/download/v$v/byob-$v-$t.tar.gz | tar xz
./byob-$v-$t/byob
Windows says "Windows protected your PC."

The Windows build isn't code-signed yet, so SmartScreen warns about it. Choose More info, then Run anyway.

Can I use it from my phone?

Yes. Start it with byob --serve and open http://127.0.0.1:7470, or put it behind tailscale serve to reach it from anywhere. It's the same app and the same chats, live.

Does it cost anything?

byob is free. A hosted model costs what its provider charges; a local one costs nothing but electricity.

From source

cargo install byob builds everything except the HTML renderer; without it, HTML apps open in your browser.

Then point it at a model

byob finds servers on their usual ports and offers presets on first run. From a terminal:

byob --inference-url http://localhost:8080/v1
BYOB_API_KEY=sk-... byob     # for a hosted API
byob --serve                 # also open it to browsers on http://127.0.0.1:7470
